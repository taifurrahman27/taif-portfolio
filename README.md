## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/taifurrahman27/taif-portfolio.git
```

### 2. Navigate to the project directory

```bash
cd taif-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```
